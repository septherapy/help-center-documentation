## Accessing the whiteboard

The whiteboard can be activated by...

Once activated, the whiteboard controls toolbar and whiteboard drawing tools will become visible. Providers are able to see and interact with both the controls toolbar and the drawing tools while other participants are only be able to see and interact with the drawing tools.

---

## Whiteboard control toolbar

The whiteboard control toolbar is visible only to providers and allows you to manage sheets, the of the whiteboard, positioning and zooming, and visibility for other participants in the therapy room.

### Sheets

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/48acf7cca29f85276c992a8b8921ab3b71235f34/images/Button%20-%20Whiteboard%20sheets.svg" width="95" height="45" alt="" style="float: right; margin: 0 0 15px 15px; border-radius: 0px" />

The sheets tool allows you to manage multiple pages for the whiteboard. Using sheets, you can annotate pages separately to be saved for later. Sheets also allows you to download whiteboard content to your computer.

### Backgrounds

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/48acf7cca29f85276c992a8b8921ab3b71235f34/images/Button%20-%20Whiteboard%20background.svg" width="126" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The background tool allows you to change the whiteboard background to a solid color, dots, grids, or lines. You can modify the opacity of colored backgrounds to adjust the transparency.

### Positioning and zoom controls

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/48acf7cca29f85276c992a8b8921ab3b71235f34/images/Button%20-%20Whiteboard%20positioning.svg" width="46" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The positioning tool allows you to move the whiteboard around independently of the content below. This is useful for aligning content on the screen or for adjusting placement after using the zoom controls. To adjust the positioning of the whiteboard, click the positioning button and drag the entire whiteboard around.

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/48acf7cca29f85276c992a8b8921ab3b71235f34/images/Button%20-%20Whiteboard%20zoom%20controls.svg" width="156" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The zoom controls allow you to zoom in and out of the whiteboard to make objects larger or smaller respectively. Zooming is handled by the plus and minus buttons with the zoom level represented in a percentage. You can reset the zoom to 100% by clicking the zoom reset button.

### Visibility

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/48acf7cca29f85276c992a8b8921ab3b71235f34/images/Button%20-%20Whiteboard%20visibility.svg" width="186" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The visibility button allows you to toggle the visibility of the entire whiteboard for other participants in the therapy room. This is useful to allow you to setup new activities or load sheets without revealing them to students until you are ready.

## Whiteboard drawing tools

The whiteboard drawing tools are visible to all participants once activated. Many of the tools have color and style options that are displayed in additional toolbars that appear in the right side of the whiteboard when the tool is activated.

<Callout kind="tip" collapsed="false">
  You can prevent students from interacting with the whiteboard drawing tools by choosing **Prevent mouse clicking in workspace** from the participant options menu. This will allow you to use the drawing tools while preventing students from modifying or changing what is on screen until you are done. Choosing **Allow mouse clicking in workspace** will allow students to interact with the whiteboard drawing tools again.
</Callout>

### Select tool

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/6a7884fd576990b50fa11394bd33f9c4dfb04179/images/Button%20-%20Select%20tool.svg" width="45" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The select tool allows you to click any object on the whiteboard to be moved or modified. Once an object has been selected, the tool options will be displayed. For example, if you selected a shape, the options for that shape will be displayed to change its style.

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/4dda3dbc1bcc1f4919b4d1b0b9ab4023ea1d4415/images/Interface%20-%20Select%20tool%20options.svg" width="164" height="84" alt="" style="width: 124; height: 44; float: right; margin: 0 0 15px 15px;" />

Additionally, the select tool has additional functionality that will be displayed under the object when selected. These buttons allow you to duplicate the object, modify the placement of the object in relation to other objects on the whiteboard (forwards or backwards), or delete the object.

<Tabs>
  <Tab title="Moving objects">
    To move an object, click and drag it across the whiteboard to its new placement.
  </Tab>

  <Tab title="Resizing objects">
    To resize an object, click and drag the circles on any of the corners or midpoints of the selected object. The circles on the corners will maintain the ratio for consistent sizing while the circles in the midpoint will resize the object without maintaining the ratio.
  </Tab>

  <Tab title="Rotating objects">
    To rotate an object, click and move in a circular directionon the blue arrow at the top of the selected object. The rotate button will always be aligned to the original top center of the object.
  </Tab>
</Tabs>

### Pen

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Pen%20tool.svg" width="45" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The pen allows you to draw free form objects on the whiteboard. You can choose the pen color and transparency, the size of the pen stroke, and the style  from solid, dashed, or dotted.

### Shapes

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/2cb87bd937f753e29a3aa0aa189d5e1b4063c4f4/images/Button%20-%20Shapes%20tool.svg" width="45" height="45" alt="" style="float: right; margin: 0px 0px 15px 15px;" />

The shapes tool allows you to add squares, rectangles, lines, ellipses/circles, triangles, or star shapes onto the whiteboard. You can choose the fill color and transparency, the border color and transparency, the width of the shape border, and the style of shape border from solid, dashed, or dotted.

### Arrow

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Arrow%20tool.svg" width="45" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The arrow tool allows you to add a line with an arrow onto the whiteboard. You can choose the arrow color and transparency, the size, and the style from solid, dashed, or dotted.

### Text

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Text%20tool.svg" width="45" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The text tool allows you to add typed words onto the whiteboard. You can choose the text color and transparency, the border color and transparency, the width of the text border, the size of the letters on screen, the font, and the style from bold, italics, or underline.

### Stamps

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Stamps%20tool.svg" width="45" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The stamps tool allows you to place emoji style stamps onto the whiteboard. You will be able to choose from a number of different stamps organized by categories such as activities, animals and nature, flags, food and drink, objects, people and body, smileys and emotion, symbols, and travel and places.

Once a stamp has been placed, you can click on it again to select it. In addition to the normal select options (see the select tool above for additional details), you can also modify the opacity of the stamp to adjust the transparency on the whiteboard.

### Erase

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Eraser%20tool.svg" width="45" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The erase tool allows you to erase the individual lines of drawings, shapes, stamps, and text from the whiteboard. This allows you to remove part of the whiteboard instead of starting a new sheet (see the sheets tool above for additionall details).

### Undo and redo

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/4dda3dbc1bcc1f4919b4d1b0b9ab4023ea1d4415/images/Button%20-%20Undo%20and%20redo%20tool.svg" width="90" height="45" alt="" style="float: right; margin: 0 0 15px 15px;" />

The undo tool allows you to revert previous actions while the redo tool allows you reapply actions that were reverted by the undo tool. These two tools can be used together to correct minor mistakes or incorrectly placed objects on the whiteboard.
