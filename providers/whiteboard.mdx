## Whiteboard drawing tools

The whiteboard drawing tools are visible to all participants. Many of the tools have color and style options that are displayed in additional toolbars that  &#x20;

### Select tool

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/6a7884fd576990b50fa11394bd33f9c4dfb04179/images/Button%20-%20Select%20tool.svg" width="45" height="45" alt="Button for the whiteboard select tool" style="float: right; margin: 0 0 15px 15px;" />

The select tool allows you to select any object on the whiteboard to be moved or modified. Once an object has been selected, the tool options will be displayed. For example, if you select shape, the options for that shape will be displayed. This will allow you to change the display of the object.

Additionally, the select tool has additional functionality that will be displayed under the object when selected.

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Interface%20-%20Select%20tool%20options.svg" width="164" height="84" alt="Buttons for the whiteboard select tool" style="width: 164; height: 84; margin: 0 auto; cursor: pointer;" />

These buttons allow you to duplicate the object, modify the placement of the object in relation to other objects on the whiteboard (forwards or backwards), or delete the object.

<Tabs>
  <Tab title="Moving objects">
    To move an object, click and drag it across the whiteboard.
  </Tab>

  <Tab title="Resizing objects">
    To resize an object, click and drag the circles on any of the corners or midpoints of the selected object. The circles on the corners will maintain the ratio for consistent sizing while the circles in the midpoint will resize the object without maintaining the ratio.
  </Tab>

  <Tab title="Rotating objects">
    To rotate an object, click and move in a circular directionon the blue arrow at the top of the selected object. The rotate button will always be aligned to the original top center of the object.
  </Tab>
</Tabs>

## Pen

<Image src="https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Pen%20tool.svg" width="45" height="45" alt="Button for the whiteboard pen tool" style="float: right; margin: 0 0 15px 15px;" />

The pen allows you to draw free form objects on the whiteboard. You can choose the pen color and transparency, the size of the pen stroke, and the style  from solid, dashed, or dotted.

### Shapes

<Image
  src="
https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Shapes%20tool.svg"
  width="45"
  height="45"
  alt="Button for the whiteboard shapes tool"
  style="float: right; margin: 0 0 15px 15px;"
/>

The shapes tool allows you to add squares, rectangles, lines, ellipses/circles, triangles, or star shapes onto the whiteboard. You can choose the fill color and transparency, the border color and transparency, the width of the shape border, and the style of shape border from solid, dashed, or dotted.  

### Arrow

<Image
  src="
https://raw.githubusercontent.com/septherapy/help-center-documentation/11f412c3929f5dee076cb73f84c474eb5164f52d/images/Button%20-%20Arrow%20tool.svg"
  width="45"
  height="45"
  alt="Button for the whiteboard arrow tool"
  style="float: right; margin: 0 0 15px 15px;"
/>

The arrow tool allows you to add a line with an arrow onto the whiteboard. You can choose the arrow color and transparency, the size, and the style from solid, dashed, or dotted.  

### Text

<Image
  src="

  height="45"
  alt="Button for the whiteboard text tool"

The text tool allows you to add typed words onto the whiteboard. You can choose the text color and transparency, the border color and transparency, the width of the text border, the size of the letters on screen, the font, and the style from bold, italics, or underline.
